# 01 가설 카드 — 메인

```
AGENTS.md와 지침서 1장 기준으로 사이클 {{번호}}의 가설 카드를 만들어 줘.

[입력]
- 가설 후보: {{예: 물리치료사를 위한 AI 임상 비서 교육}}
- 인터뷰·문의에서 나온 신호(익명 요약만): {{없으면 "없음"}}
- 쓸 수 있는 시간·비용: {{예: 주 6시간, 10만 원}}

[해 줄 것]
1. 아래 공식의 빈칸을 채운 가설 문장 1개
   "[맥락 신호 X]가 발생한 뒤 N분(일) 이내에 [개입 Y]를 제안하면,
    [비교 조건]보다 [행동 Z]가 K%p 이상 높을 것이다.
    7일 안에 K%p에 못 미치면 이 가설은 틀린 것으로 판정한다."
2. 가설 카드 9칸 (가설 한 줄, 맥락 신호, 개입, 비교 조건, 행동 지표, 반증 기준, 투입 상한, 제외 목록, 판정)
   - 개입은 강요가 아닌 초대 형태로
   - 행동 지표는 신청·회신·대기자 등록 같은 실제 행동으로
   - 반증 기준 K는 숫자로 제안하되 근거 등급을 붙이고, 근거가 없으면 C
3. 타이밍 점수 3요소(M 동기·결핍, T 상황 트리거, F 마찰)별로 우리가 측정할 신호
4. 시작 조건 5개 중 아직 안 된 것과 그걸 채우려면 필요한 것

[출력]
- 먼저 사람이 읽을 요약 (10줄 이내)
- 그다음 site/data/hypothesis.json의 "cycle", "card", "timing" 부분을 docs/schema.md 형식 그대로 JSON으로
- 확인하지 못한 값은 null. 숫자를 지어내지 말 것
```
