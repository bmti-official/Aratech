# 06 사람 승인 — 사업 총괄 · 멘토

코드는 볼 필요 없다. PR에 자동으로 달리는 **📋 변경 요약** 댓글만 읽는다.

1. PR을 열고 변경 요약 댓글을 읽는다
2. 댓글 맨 아래 "승인하는 사람이 할 일"을 따른다
   - 👍 간단한 변경: 요약이 의도와 맞으면 **Merge pull request → Confirm merge**
   - 🔍 검수 필요: "검수용 문구"를 복사해 **새** Claude 대화에 붙여 넣고, "검수 통과"면 Merge
   - ❌ 검사 오류: Merge하지 않고 댓글로 "고쳐 주세요"
3. 판정(유지 / 수정 / 중단)이 들어간 PR이면, 그 판정을 내가 내린 것이 맞는지 한 번 더 본다

Merge하지 않을 때는 PR 댓글에 고칠 점을 한국어로 적는다. 에이전트는 그 댓글을 보고 다시 작업한다.
