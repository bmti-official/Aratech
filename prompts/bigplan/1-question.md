# 대형 기획 1 질문 정의 — 메인

월 1~2회, 한 건에 질문 하나.

```
대형 기획 질문을 정리해 줘. 질문 팩: {{A 수익 모델 / B 불안·욕망·커리큘럼 / C AGI 병목·독점 구조}}

[원래 질문] {{붙여 넣기}}
[이미 정해진 입력값] {{N, P, M 등. 없으면 "없음"}}

1. 한 문장 질문
2. 세 렌즈(틸·게이츠·저커버그)가 공통으로 받을 입력값 목록, 비어 있는 값 표시
3. 근거 팩에 필요한 공개 자료 목록 (근거 서브에이전트에 넘김)
4. 공개 범위: 사이트에 올릴 것(결론 한 줄)과 제한 문서에 둘 것
5. 최종 답변 양식: 한 페이지 요약(결론 3줄, 렌즈 간 합의, 충돌, 핵심 숫자, 사업 총괄이 정할 결정 3가지) + 부록

결과를 work/bigplan/{{날짜}}/question.md로 저장할 수 있게 마크다운으로.
```

다음: 메인이 근거 서브에이전트에 근거 팩을 맡긴다 (`02-evidence.md`를 질문에 맞게 바꿔 쓰고, 결과는 `work/bigplan/{{날짜}}/evidence.md`).
