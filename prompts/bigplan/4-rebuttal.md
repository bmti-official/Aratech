# 대형 기획 4 교차 반박 — 각 렌즈 담당

세 렌즈 파일이 모두 나온 뒤, 각 담당 에이전트에 다른 두 렌즈 파일을 준다.

```
너는 {{틸 / 게이츠 / 저커버그}} 렌즈 담당이야.
work/bigplan/{{날짜}}/의 다른 두 렌즈 분석({{파일명 2개}})을 읽고,
각각에서 가장 큰 약점을 1개씩만 지적해 줘.
- 약점마다: 무엇이 약한지 / 왜 (근거 등급 포함) / 무엇을 확인하면 풀리는지
- 자기 렌즈 분석은 고치지 않는다
- work/bigplan/{{날짜}}/rebuttal-<너의 렌즈>.md로 저장
```
