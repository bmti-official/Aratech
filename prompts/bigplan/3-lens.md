# 대형 기획 3 렌즈 분석 — 렌즈 서브에이전트 3개가 따로

메인이 서브에이전트 3개를 동시에 띄운다. 세 렌즈는 **서로의 결과를 보지 않는다.** 같은 question.md와 evidence.md만 받는다.
각자 `work/bigplan/{{날짜}}/lens-<이름>.md`에 저장한다.

## 공통 문구 (세 렌즈 모두 앞에 붙임)

```
AGENTS.md를 따라 줘. work/bigplan/{{날짜}}/question.md의 질문을
work/bigplan/{{날짜}}/evidence.md의 근거만 써서 아래 렌즈로 분석해 줘.
- 렌즈는 공개된 저서·사례에서 정리한 분석 틀이다. "이 틀로 보면 ○○를 점검해야 한다"로 쓰고,
  그 사람이 할 법한 말을 지어내거나 인용하지 않는다
- 모든 주장에 근거 등급(A/B/C). 근거 팩에 없는 숫자는 C로 표시
- 다른 렌즈 파일은 열지 않는다
- 출력: 핵심 판단 3줄 / 점검 항목별 0~5점과 근거 / 가장 약한 고리 / 이 렌즈가 놓치기 쉬운 것
```

## 틸 렌즈 — 서브에이전트 1
점검 항목: 대체재보다 크게 우월한 기술, 네트워크 효과, 규모의 경제, 브랜드, 비밀(남들이 모르는 진실), 타이밍, 작은 시장에서 시작해 넓히는 경로

## 게이츠 렌즈 — 서브에이전트 2
점검 항목: 제3자가 올라타는 플랫폼과 생태계, 표준과 호환성, 배포 채널, 낮은 한계비용, 사용자의 전환 비용

## 저커버그 렌즈 — 서브에이전트 3
점검 항목: 네트워크 효과와 성장 속도, 핵심 지표 중심의 빠른 반복, 커뮤니티 성장, 경쟁 위협 대응(인수 포함)
