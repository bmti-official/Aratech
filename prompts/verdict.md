# 7일차 판정과 회고 — Claude (판정은 사람)

```
사이클 {{번호}}의 7일차야. 판정에 쓸 자료를 정리해 줘. 판정은 내가 한다.

[입력]
- 가설 카드: site/data/hypothesis.json
- 반증 기준: {{K%p}}
- 실측 (익명 집계만): 노출 {{ }}, 행동 {{ }}, 비교 조건 노출 {{ }}, 행동 {{ }}
- 전환 속도, 자발적 유지율: {{ }}

[해 줄 것]
1. 반증 기준 대비 실측치 (차이, 표본 수, 등급)
2. 표본이 작으면 p값 대신 미리 정한 효과 크기·방향·반복 관찰 여부로
   "지지 신호 / 반대 신호 / 판단 불가" 중 하나를 제안하고 이유
3. 유지 / 수정 / 중단 각각을 골랐을 때 다음 사이클 가설 후보
4. 배운 점 3줄

[출력]
history 배열에 넣을 항목(JSON, verdict는 비워 둠) + 요약.
내가 verdict를 정하면 그 값을 넣고 cycle.status를 "판정 완료"로 바꿔 PR.
```
