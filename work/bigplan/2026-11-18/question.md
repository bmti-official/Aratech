# 대형 기획 질문 (일반판) — 2026-11-18

질문 팩: C (AGI 시대 병목·독점 구조)
이 파일은 외부 도구(Gemini)와 공유하는 **일반 질문**이다. 특정 회사의 계획은 담지 않는다 (AGENTS.md §2-7).

## 한 문장 질문
물리치료(근골격계 재활) 기록 AI 분야에서, 현장에서 쌓이는 기록 데이터가 경쟁자가 따라오기 어려운 해자가 되는 일반 구조는 무엇이고, 어떤 조건에서는 해자가 되지 못하는가?

## 렌즈가 공통으로 받을 입력값
| 입력값 | 값 | 비고 |
|---|---|---|
| 국내 물리치료사 활동 인원 | 미확인 | 근거 팩에서 확인 |
| 국내 물리치료 기관의 EMR 구성(병원급·의원급) | 미확인 | 근거 팩에서 확인 |
| 해외 의료 기록 AI 기업 사례 | 조사 아카이브 P001 (site/data/posts.json) | Abridge, Ambience, Nabla, Olive AI |
| 의료 데이터 가명처리 기준 | work/evidence/pseudonymization.md 사실 칸 | 해석 칸은 쓰지 않는다 |
| 대형 범용 AI 모델의 의료 기록 성능 추세 | 미확인 | 근거 팩에서 확인 |

## 근거 팩에 필요한 공개 자료
1. 재활·물리치료 결과(outcome) 데이터 레지스트리 사례와 그 사업적 위치 (예: 미국 물리치료 결과 측정 서비스)
2. 의료 기록 AI 기업이 데이터를 경쟁 우위로 내세운 공개 사례와, 데이터 해자가 약하다는 공개 분석
3. 범용 대형 AI 모델이 의료 기록·요약에서 전문 모델을 따라잡은 공개 평가
4. 국내 물리치료사 인원, 물리치료 기관 수, 물리치료 기록 관련 제도(진료기록 보존 등)
5. 국내 보건의료 데이터 활용 제도(가명정보 결합, 데이터 심의) 중 해자 형성에 영향을 주는 것
6. 의료 데이터 네트워크 효과(사용자가 늘수록 품질이 좋아지는 구조)가 실제로 확인된 사례와 반례

## 최종 답변 양식
한 페이지 요약(결론 3줄, 렌즈 간 합의, 충돌, 핵심 숫자, 정할 결정 3가지) + 부록
