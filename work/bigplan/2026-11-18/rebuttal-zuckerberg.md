## 게이츠 렌즈(`lens-gates.md`)의 가장 큰 약점 1개

### 1. 무엇이 약한지
**파편화된 국내 중소병원·의원급 상용 EMR 환경에서 '기존 상용 EMR 번들링·파트너십'을 핵심 배포 채널이자 데이터 해자 형성의 출발점으로 상정한 점 (핵심 판단 2, 점검 항목 3·5)**

게이츠 렌즈는 개별 의료기관 직접 영업 대신 기존 상용 EMR·청구 소프트웨어에 기본 계층으로 탑재(번들링)하거나 파트너십을 맺어 배포 채널을 확보하고, 그 위에서 표준 스키마와 결과(Outcome)·청구 데이터를 축적해 전환 비용과 다면 생태계를 만들어야 한다고 분석했다(C). 그러나 저커버그 렌즈(초기 확산 속도, 핵심 지표의 빠른 반복 루프, 플랫폼 종속 및 경쟁 위협 대응의 틀)로 보면, 이 전략은 **① 초기 배포·반복 속도의 병목**과 **② 상용 EMR 플랫폼에 의한 기능 흡수 및 데이터 주도권 상실**이라는 두 가지 구조적 모순을 안고 있다(C).

---

### 2. 왜 약한지 (근거 및 등급)

1. **미국 단일 대형 EHR(Epic) 통합 사례를 비표준·파편화된 국내 중소병원·의원급 환경에 대입한 확산 속도(Growth Speed) 오류**:
   - 게이츠 렌즈는 배포 채널 전략의 핵심 근거로 Abridge가 2023-08 Epic의 첫 Pal 파트너로 통합된 뒤 2026-06 보도 기준 300곳 이상의 의료 시스템으로 확산된 사례(등급 **B**, F2-1)를 들었다.
   - 하지만 국내 전체 의료기관의 EMR 도입률은 상급종합병원 100%, 종합병원 94.0%~97.5%, 병원급 90.5%~95.4% 수준이더라도 중소병원·의원급은 외부 상용 EMR 구매·구독 중심이며, 국가 공인 EMR 사용인증률은 상급종합병원 100%, 종합병원 약 52%인 데 비해 **병원급은 약 4%, 의원급은 약 11%**에 불과하다(등급 **A/B**, 입력값 확인 표). 더욱이 물리치료 실시기관만 별도로 분리한 병원급·의원급 EMR 업체 점유율은 공개 통계에서 **미확인**이며, 국내 물리치료사 인원 수치(면허 83,671명, 활동 60,501명, 요양기관 47,724명)와 물리치료기록부 5년 보존 규정 또한 원문 미확인 상태다(등급 **C**, 메인 확인 표).
   - 이 틀로 보면, 공인 표준 인증률이 4~11%에 그치는 파편화된 중소병원·의원급 상용 EMR 시장에는 한 번의 제휴로 수백 개 기관에 표준 배포가 가능한 단일 지배적 파이프라인이 확인되지 않는다(C). 따라서 상용 EMR 번들링에 의존하면 오히려 업체별 제휴 협상과 상이한 DB 구조에 맞춘 병원별 수작업 통합 비용(IBM Watson for Oncology가 비정형 EMR 통합 비용으로 해체·매각된 반례, 등급 **B**, F6-2)에 갇혀 초기 성장 속도와 제품 피드백 루프가 정지할 위험이 크다(C).

2. **범용 모델의 요약 기능 범용화 및 데이터 규제 속에서, 외부 EMR 하위 번들 진입 시 발생하는 '경쟁 흡수·데이터 통제권 상실' 위협**:
   - 범용 파운데이션 모델의 성능 향상으로 단순 진료 대화 요약·노트 생성 기능 자체는 빠르게 범용화(commodity)되고 있으며(등급 **B**, F2-3; 스탠퍼드대 연구의 인간 전문가 대비 동등 45%·우수 36%·합계 81% 수치는 원문 접속 차단으로 미확인 상태이므로 등급 **C**, 메인 확인 표), 전문 모델이 차별화 점수를 받는 영역은 고밀도 의학 전문용어·미등록 어휘(OOV) 처리와 간결성 등 현장 미세조정 영역이다(등급 **A**, F3-2).
   - 또한 미국의 외래 재활 결과 측정 시스템인 FOTO조차 독자적인 제3자 플랫폼 생태계로 남지 못하고 의료 소프트웨어 기업 Net Health에 인수되어 EHR 연동 서비스로 편입되었으며(등급 **B**, F1-1), APTA의 공식 결과 레지스트리는 인프라 유지 및 재정 부담으로 2022 MIPS 보고 연도 제출 후 운영을 종료했다(등급 **A**, 메인 확인 표·F1-2).
   - 여기에 국내 규정상 진료대화 AI 활용 시 기업용(Enterprise API) 라이선스, 보관·재학습·국외이전 여부 고지, 데이터 처리 계약 체결, 민감정보(건강정보) 별도 동의 또는 법령 근거가 요구되고(등급 **A**, F5-3), 자유입력 진료기록의 자연어 처리 정형화·가명처리(등급 **A**, F5-1) 및 연구·상용화 시 5인 이상(외부위원 2인 이상) 데이터심의위원회(DRB) 승인과 다기관 결합 시 결합전문기관·반출심사위원회 통과가 필수다(등급 **A**, F5-2).
   - 이 틀로 보면, 기록 AI가 독자적인 사용자 접점과 핵심 워크플로 지표(타임스탬프 기반 감사 추적 Linked Evidence **B** F2-1, 청구 무결성 AutoCDI **B** F2-2, 물리치료 OOV 적응 **A** F3-2)의 직접 통제권을 쥐지 못한 채 기존 상용 EMR의 하위 번들 기능으로 들어가면, 의료기관과의 데이터 처리 계약(A, F5-3) 주도권과 법정 보존 기록(진료기록부 10년·간호기록부 5년 **A**, 물리치료기록부 5년은 원문 미확인 **C**, 메인 확인 표·F4-2)의 전환 비용이 모두 기존 상용 EMR 업체에 귀속된다(C). 결과적으로 상용 EMR 업체가 자체적으로 범용 LLM Enterprise API를 연결해 요약 기능을 내재화할 경우, 번들 파트너였던 기록 AI는 데이터 루프도 돌리지 못한 채 즉시 대체될 취약성이 크다(C).

### 3. 무엇을 확인하면 풀리는지 (검증 과제)

게이츠 렌즈가 제안한 '상용 EMR 번들링·표준 스키마 선점' 전략이 실제 해자로 작동할 수 있는지 판정하려면 다음 3가지를 추가로 확인해야 한다.

1. **국내 물리치료 청구 기관(심평원 신고 기관, A, F4-3)의 상용 EMR 상위 업체 집중도**:
   - 물리치료를 실시하는 병원급·의원급 기관(현재 업체별 점유율 **미확인**, 입력값 확인 표)에서 상위 1~3개 상용 EMR·청구 소프트웨어의 합산 점유율이 소수 제휴만으로도 임계 규모 배포가 가능한 수준인지, 아니면 수십 개 비표준 업체로 쪼개져 있는지 확인해야 한다.
2. **외부 상용 EMR 연동 방식(API·오버레이 vs 종속 번들)에 따른 데이터 계약 주체 및 핵심 지표 피드백 속도**:
   - 상용 EMR과 전면 제휴하지 않고도 화면 오버레이·클립보드·청구 코드 매핑(AutoCDI, B, F2-2)이나 감사 추적(Linked Evidence, B, F2-1) 형태로 물리치료사 접점을 직접 확보해, 의료기관과 직접 데이터 처리 계약(A, F5-3)을 맺고 도메인 어휘(OOV, A, F3-2) 반복 개선 루프를 돌릴 수 있는지 확인해야 한다.
3. **상용 EMR 파트너십 시 데이터 귀속·재학습 권한과 자체 LLM 내재화 방어 조건**:
   - 기존 상용 EMR 업체와 파트너십을 맺을 때 가명처리·정형화된 결과 데이터(A, F5-1·F5-2)의 상용화 권리를 누가 갖는지, 그리고 EMR 업체가 범용 LLM(B, F2-3)을 직접 붙여 기능을 복제하는 것을 막을 독점 연동 조건이나 Net Health-FOTO(B, F1-1)와 같은 인수·합병 경로가 실제로 존재하는지 확인해야 한다.
