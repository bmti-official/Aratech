# 사이클 1 커리큘럼 초안

과정명(가안): 환자 정보를 지키는 AI 임상 비서: 음성 차팅부터 임상 워크플로우까지
대상: 기록 업무 부담이 큰 물리치료사
형식: 온라인 실시간 5회 × 90분, 수료 후 실습 도구 30일 사용
원칙:
- 실습은 가상 환자 데이터로만 한다. 실제 환자 정보는 쓰지 않는다
- 실습 도구가 우리 제품이라는 사실을 1회차에 밝힌다
- 법 내용은 사실대로: "일반 AI는 불법"이 아니라 "환자 정보를 넣으려면 기업용 계약·고지·가명처리가 필요하다"
  (근거: work/evidence/pseudonymization.md)
- 측정하지 않은 효과 숫자("10초 만에" 등)를 약속하지 않는다

## 1회차 · AI 임상 비서 이해: 물리치료실은 진료실과 다르다
- 해외 사례(Abridge, Nabla)는 의사 진료실 중심. 물리치료실의 차이: 오픈 공간과 소음, 간헐적 대화, 운동 지시와 신체 접촉
- 음성 입력 방식: 치료 직후 1분 요약 녹음(기본) / 실시간 녹음(1인 공간과 동의가 있을 때만, 통신비밀보호법 주의: 타인 간 대화 녹음 금지)
- 실습: 내 기록 업무 시간 재기, 가장 스트레스받는 차팅 유형 1가지 정하기 (3·4회차 재료)

## 2회차 · 환자 정보 지키기: 현장 딜레마로 배우기
- 딜레마 사례 중심 진행
- 보안 3단계 기준표
  | 등급 | 예시 | 개인용 AI 계정 | 기업용 계약된 도구 |
  |---|---|---|---|
  | 절대 입력 금지 | 이름, 주민번호, 연락처, 얼굴·신체 사진 | 불가 | 불가 (도구 기능에 맞춰 별도 처리) |
  | 가명처리 후 입력 | 진단명, 검사 수치, 경과 | 불가 | 가능 |
  | 자유 입력 | 일반 운동법, 개인 정보 없는 양식 | 가능 | 가능 |
- 물리치료 비식별 Before & After: 희귀 질환명 → 질환 범주, 사고 일시 → "○주 전", 드문 직업 → 넓은 직업군, 나이 → 10세 구간

## 3회차 · 음성 차팅 실습과 검증
- 한국어+의학영어 혼용과 줄임말(예: "L-spine HNP, SLR 45도 양성") 인식과 표준화
- 실습 도구로 가상 시나리오 차팅 (1회차 스트레스 유형 반영)
- 물리치료 AI 차트 검증 체크리스트
  - 좌·우, 부위, 레벨(L4-5 등) 혼동
  - MMT, ROM, 통증 점수(NRS/VAS) 수치·단위 왜곡
  - S(환자 호소)와 O(치료사 소견) 섞임
  - 하지 않은 검사·치료가 들어감(환각)
  - 치료 시간·횟수·종류 오류
  - 날짜, 경과 방향(호전/악화) 반대로 적기
- 실습: AI 초안 "틀린 그림 찾기"

## 4회차 · 임상 워크플로우 확장
- 나만의 SOAP 템플릿: 근골격계, 신경계, 도수치료, 스포츠 재활 등 분야별 출력 형식
- 2차 산출물 (같은 차팅 데이터 재활용)
  - 환자용 홈 프로그램(HEP) 안내문: 쉬운 말로 작성 → 치료사 확인 → 실습 도구(웹)에서 환자에게 일방향 전달.
    치료사의 카톡·전화번호는 공유하지 않는다. 환자는 자료를 받아 보기만 하고 채팅·답장 기능은 없다.
  - 타과·의사 소견서(Referral) 요약
  - 초기 평가(Initial Evaluation) 데이터 구조화
- 실습: 내 차트 1건 → HEP 안내문 → 전달 화면까지, 걸린 시간 직접 재기

## 5회차 · 정확한 기록과 내 병원 적용
- 부당한 삭감을 막는 기록: 의학적 필요성과 경과를 빠짐없이. 실제로 한 치료, 실제로 관찰한 변화만 쓴다
- EMR 현실 대안: 복사·붙여넣기 동선 줄이기 (단축키, 듀얼 모니터, 템플릿 순서를 EMR 칸에 맞추기)
- 원장·관리자 설득용 1-Pager 템플릿: 보안, 기록 품질, 삭감 위험, 치료사 연락처를 노출하지 않는 환자 안내.
  효과 수치는 수강생이 직접 잰 값이나 출처 있는 값만
- 실습: 내 병원 도입 체크리스트(동의서, 계약, 보관 기간)와 1-Pager 초안

## 실습 도구(OS)에 필요한 기능 (커리큘럼 운영 조건)
- HEP 일방향 전달: 치료사가 확인 후 "전달" 버튼, 환자는 열람만 (채팅·답장 없음, 치료사 연락처 비노출)
- 환자 안내문 수신 동의 받기
- 전달 링크 만료 기간 설정
- 안내문에 진단명 등 민감정보 최소화
- 가상 환자 시나리오 모드 (교육용)
